Runs de talles

Escales pures. Un run diu quines talles hi ha i en quin ordre — res més. La graduació viu als jocs de regles; les restriccions ordenen la proposta al wizard, mai amaguen.

—
Què fixa aquesta versió
  • Mateix patró que el catàleg de POMs: llista a l'esquerra, fitxa a la dreta, mateixes accions. Un sol llenguatge per a tota la Configuració tècnica.
  • Els presets amb graduació dins han desaparegut. Un run és una escala; els increments de POM viuen als jocs de regles. Aquí no hi ha ni un delta.
  • Les quatre capes de restricció s'editen a la fitxa (target · construcció · fit · grup), multi-selecció. Cap seleccionada = serveix a tothom.
  • «On s'usa» compta també les regles ancorades a les SEVES TALLES, no només el que apunta al run. És la lliçó del 07/08: un run amb «0 usos» era l'àncora de talla base de 350 regles de deu jocs que eren d'altres runs.
  • Amb ús, no s'esborra: es desactiva. El botó ho diu i el motiu també.
Tres coses que he decidit jo
  • Les talles es veuen amb el seu ordre explícit (1, 2, 3…). Dos runs es llegien desordenats perquè l'ordre estava duplicat, i un run desordenat és un grading incorrecte: si es veu, no torna a passar.
  • «Clonar» es queda — és com neix un run de client a partir d'un canònic sense tocar l'original.
  • El tipus d'escala es mostra, no s'edita a mà: el dedueix el sistema de les etiquetes. Si el que hi ha escrit contradiu les etiquetes, la fitxa ho avisa en comptes de deixar-ho passar.
