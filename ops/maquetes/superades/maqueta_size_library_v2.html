Runs de talles

Escales pures. Un run diu quines talles hi ha i en quin ordre — res més. La graduació viu als jocs de regles; les restriccions ordenen la proposta al wizard, mai amaguen.

—
Què fixa aquesta v2 (estructura = v1 aprovada · pell = NORMA_LAYOUT v1)
  • Mateix patró que el catàleg de POMs: llista a l'esquerra, fitxa a la dreta, mateixes accions. Un sol llenguatge per a tota la Configuració tècnica.
  • Els presets amb graduació dins han desaparegut. Un run és una escala; els increments de POM viuen als jocs de regles. Aquí no hi ha ni un delta.
  • Les quatre capes de restricció s'editen a la fitxa (target · construcció · fit · grup), multi-selecció. Cap seleccionada = serveix a tothom.
  • «On s'usa» compta també les regles ancorades a les SEVES TALLES, no només el que apunta al run. Lliçó 07/08: un run amb «0 usos» era l'àncora de talla base de 350 regles de deu jocs.
  • Amb ús, no s'esborra: es desactiva. El botó ho diu i el motiu també.
  • Pell NORMA v1: capçaleres blanques · «＋ Nou run» únic blau · chips en píndola triats amb --sel+vora daurada · badge ÀNCORA en taronja viu amb tinta fosca · avisos amb --err/--ok de la norma · cap text sota 10px.
Decisions heretades de la v1 (vigents)
  • Les talles es veuen amb el seu ordre explícit (1, 2, 3…). Un run desordenat és un grading incorrecte: si es veu, no torna a passar.
  • «Clonar» es queda — és com neix un run de client a partir d'un canònic sense tocar l'original.
  • El tipus d'escala es mostra, no s'edita a mà: el dedueix el sistema de les etiquetes; si el que hi ha escrit les contradiu, la fitxa avisa.
